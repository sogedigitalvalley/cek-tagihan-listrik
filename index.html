Kebijakan ini menjelaskan data apa yang dipakai aplikasi Cek Tagihan Listrik, untuk apa, dan bagaimana kami menjaganya. Aplikasi ini bukan aplikasi resmi PLN. Pembayaran diteruskan melalui mitra pembayaran tagihan resmi.

Data yang kami proses

  • ID pelanggan atau nomor meter PLN yang Anda ketik atau scan, untuk mengecek tagihan dan membeli token.
  • Data transaksi: nomor transaksi, jenis layanan, nominal, status, nomor referensi PLN, dan token listrik. Nama pelanggan PLN dapat tampil dari data tagihan.
  • Pembayaran QRIS diproses oleh penyedia pembayaran berizin. Kami tidak menerima atau menyimpan data rekening, kartu, PIN, maupun saldo e-wallet Anda.
  • Data teknis jaringan seperti alamat IP dipakai sementara untuk keamanan (mencegah penyalahgunaan) dan tidak dipakai untuk mengenali Anda.

Data yang hanya tersimpan di HP Anda

  • Meter Saya (nama dan ID meter), riwayat transaksi, pengaturan tarif, pengingat, dan daftar alat listrik.
  • Foto meter untuk fitur scan dibaca langsung di HP dan tidak diunggah ke server kami.
  • Data ini terhapus bila aplikasi dihapus atau datanya dibersihkan.

Iklan

Aplikasi menampilkan iklan dari Google AdMob setelah 7 hari sejak dipasang, hanya di Beranda dan Riwayat. AdMob dapat memakai ID iklan perangkat dan data teknis sesuai kebijakan iklan Google. Anda dapat mengatur ID iklan di Setelan Android, bagian Google, lalu Iklan.

Pihak yang menerima data

  • Mitra pembayaran tagihan resmi: ID pelanggan/nomor meter dan nominal, untuk mengecek dan membayar ke PLN.
  • Penyedia pembayaran QRIS: nomor transaksi dan nominal, untuk membuat QRIS dan mengonfirmasi pembayaran.
  • Google AdMob: untuk menayangkan iklan.

Mitra hanya menerima data yang diperlukan untuk menyelesaikan transaksi. Kami tidak menjual data Anda.

Penyimpanan dan keamanan

Semua komunikasi memakai koneksi terenkripsi (HTTPS). Data transaksi disimpan selama diperlukan untuk layanan, penanganan keluhan, dan pengembalian dana, paling lama 2 tahun, lalu dihapus.

Hak Anda

Anda dapat meminta salinan atau penghapusan data transaksi dengan menghubungi kami dan menyebutkan nomor transaksi atau ID pelanggan.

Anak-anak

Aplikasi ini ditujukan untuk pengguna dewasa yang membayar listrik dan tidak ditujukan untuk anak-anak.
